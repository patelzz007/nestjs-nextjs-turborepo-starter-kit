## Installation

`EntityAvatar` and `getEntityAvatarTone` ship with the kit in `packages/ui/src/components/entity-avatar.tsx`; there is nothing to install.

```showcase-example
c-entity-avatar-1
```

## Usage

```tsx
import { EntityAvatar } from "@workspace/ui/components/entity-avatar";
```

```tsx
<EntityAvatar name="Acme Coffee" src={merchant.logoUrl} size="lg" />
```
