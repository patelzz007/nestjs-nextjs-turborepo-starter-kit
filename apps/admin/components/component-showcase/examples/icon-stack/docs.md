## Installation

`IconStack` ships with the kit in `packages/ui/src/components/icon-stack.tsx`; there is nothing to install.

```showcase-example
c-icon-stack-1
```

## Usage

```tsx
import { IconStack } from "@workspace/ui/components/icon-stack";
```

```tsx
<IconStack aria-hidden="true">
	<InboxIcon className="size-4" />
</IconStack>
```
