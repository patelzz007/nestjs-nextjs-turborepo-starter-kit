## Installation

`RichTextView` ships with the kit in `packages/ui/src/components/rich-text-view.tsx`; there is nothing to install.

```showcase-example
c-rich-text-view-1
```

## Usage

```tsx
import { RichTextView } from "@workspace/ui/components/rich-text-view";
```

```tsx
<RichTextView document={broadcast.body} />
```
