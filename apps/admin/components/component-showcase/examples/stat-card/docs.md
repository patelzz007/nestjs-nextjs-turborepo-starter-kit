## Installation

`StatCard` ships with the kit in `packages/ui/src/components/stat-card.tsx`; there is nothing to install.

```showcase-example
c-stat-card-1
```

## Usage

```tsx
import { StatCard } from "@workspace/ui/components/stat-card";
```

```tsx
<StatCard label="Active merchants" value="1,284" hint="+42 this week" icon={<Store aria-hidden="true" />} />
```
