## Installation

`Alert` ships with the kit in `packages/ui-native/src/components/alert.tsx`; there is nothing to install.

```showcase-example
c-alert-1
```

## Usage

```tsx
import { Alert } from "@workspace/ui-native/components/alert";
```

```tsx
<Alert tone="error" title="Payment failed" message="Update your card to continue." />
```

## Accessibility

- Errors are alerts announced assertively; other tones are summaries announced politely.
- The close button is named "Dismiss"; glyphs and avatars are decorative.
