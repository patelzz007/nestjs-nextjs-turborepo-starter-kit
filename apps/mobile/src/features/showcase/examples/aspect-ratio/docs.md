## Installation

`AspectRatio` ships with the kit in `packages/ui-native/src/components/aspect-ratio.tsx`; there is nothing to install.

```showcase-example
c-aspect-ratio-1
```

## Usage

```tsx
import { AspectRatio } from "@workspace/ui-native/components/aspect-ratio";
```

```tsx
<AspectRatio ratio={16 / 9}>{children}</AspectRatio>
```
