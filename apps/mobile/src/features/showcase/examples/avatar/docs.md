## Installation

`Avatar` ships with the kit in `packages/ui-native/src/components/avatar.tsx`; there is nothing to install.

```showcase-example
c-avatar-1
```

## Usage

```tsx
import { Avatar } from "@workspace/ui-native/components/avatar";
```

```tsx
<Avatar name="Sofia Davis" imageUrl={photo} badges={[{ label: "Online" }]} />
```
