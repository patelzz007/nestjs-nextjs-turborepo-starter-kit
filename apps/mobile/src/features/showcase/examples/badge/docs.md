## Installation

`Badge` ships with the kit in `packages/ui-native/src/components/badge.tsx`; there is nothing to install.

```showcase-example
c-badge-1
```

## Usage

```tsx
import { Badge } from "@workspace/ui-native/components/badge";
```

```tsx
<Badge label="Paid" tone="success" variant="light" />
```

## Accessibility

- The label is the badge's text; glyphs, dots and avatars are decorative.
- The remove button is named "Remove <label>"; a link badge is a link.
