## Installation

`Bubble` ships with the kit in `packages/ui-native/src/components/bubble.tsx`; there is nothing to install.

```showcase-example
c-bubble-1
```

## Usage

```tsx
import { Bubble } from "@workspace/ui-native/components/bubble";
```

```tsx
<Bubble text="On my way!" variant="sent" />
```

## Accessibility

- Name a bubble for its sender with `accessibilityLabel` ("You: …") when the side alone carries it.
- Reactions are images named by who reacted and how.
