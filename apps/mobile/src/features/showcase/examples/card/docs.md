## Installation

`Card` ships with the kit in `packages/ui-native/src/components/card.tsx`; there is nothing to install.

```showcase-example
c-card-1
```

## Usage

```tsx
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@workspace/ui-native/components/card";
```

```tsx
<Card title="Devices" description="Where you are signed in">
	<DeviceList />
</Card>
```

## Accessibility

- Titles are headers for screen readers.
- Only the controls inside a card are focusable; the card itself is not.
