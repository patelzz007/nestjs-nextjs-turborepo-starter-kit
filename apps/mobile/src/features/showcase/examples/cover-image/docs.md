## Installation

`CoverImage` ships with the kit in `packages/ui-native/src/components/cover-image.tsx`; there is nothing to install.

```showcase-example
c-cover-image-1
```

## Usage

```tsx
import { CoverImage } from "@workspace/ui-native/components/cover-image";
```

```tsx
<CoverImage uri={url} alt="Code on a laptop screen" />
```
