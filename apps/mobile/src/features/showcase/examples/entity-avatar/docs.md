## Installation

`EntityAvatar` ships with the kit in `packages/ui-native/src/components/avatar.tsx`; there is nothing to install.

```showcase-example
c-entity-avatar-1
```

## Usage

```tsx
import { Avatar } from "@workspace/ui-native/components/avatar";
```

```tsx
<Avatar name="Acme Coffee" imageUrl={logo} shape="rounded" tone="name" />
```
