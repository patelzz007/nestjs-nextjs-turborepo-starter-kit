## Installation

`IconStack` ships with the kit in `packages/ui-native/src/components/icon-stack.tsx`; there is nothing to install.

```showcase-example
c-icon-stack-1
```

## Usage

```tsx
import { IconStack } from "@workspace/ui-native/components/icon-stack";
```

```tsx
<IconStack tone="primary">
	<Icon icon={InboxIcon} size="sm" colorClassName="accent-primary" />
</IconStack>
```
