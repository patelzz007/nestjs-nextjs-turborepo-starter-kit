## Installation

`IconTile` ships with the kit in `packages/ui-native/src/components/icon-tile.tsx`; there is nothing to install.

```showcase-example
c-icon-tile-1
```

## Usage

```tsx
import { IconTile } from "@workspace/ui-native/components/icon-tile";
```

```tsx
<IconTile icon={WalletIcon} tone="green" />
```

## Accessibility

- Decorative tiles are hidden from screen readers.
- An interactive tile is a named link (or button).
