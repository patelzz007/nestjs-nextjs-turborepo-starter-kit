## Installation

`ImageCarousel` ships with the kit in `packages/ui-native/src/components/image-carousel.tsx`; there is nothing to install.

```showcase-example
c-image-carousel-1
```

## Usage

```tsx
import { ImageCarousel } from "@workspace/ui-native/components/image-carousel";
```

```tsx
<ImageCarousel images={images} index={index} onChange={setIndex} showCounter />
```
