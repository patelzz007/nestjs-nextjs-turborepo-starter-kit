## Installation

`ImageResizer` ships with the kit in `packages/ui-native/src/components/image-resizer.tsx`; there is nothing to install.

```showcase-example
c-image-resizer-1
```

## Usage

```tsx
import { ImageResizer } from "@workspace/ui-native/components/image-resizer";
```

```tsx
<ImageResizer uri={url} alt="A laptop" value={size} onChange={setSize} aspectRatio={16 / 9} />
```
