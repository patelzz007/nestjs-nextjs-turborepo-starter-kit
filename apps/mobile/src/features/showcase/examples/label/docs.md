## Installation

`Label` ships with the kit's text roles in `packages/ui-native/src/components/text.tsx`; there is nothing to install.

```showcase-example
c-label-1
```

## Usage

```tsx
import { Label } from "@workspace/ui-native/components/text";
```

```tsx
<Label>Server status</Label>
```

## Accessibility

- A label in a `Field` names its control; on its own it is plain text.
- It follows the system text size.
