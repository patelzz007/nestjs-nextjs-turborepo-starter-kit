## Installation

`Menubar` ships with the kit in `packages/ui-native/src/components/menubar.tsx`; there is nothing to install.

```showcase-example
c-menubar-1
```

## Usage

```tsx
import { Menubar, type MenubarMenu } from "@workspace/ui-native/components/menubar";
```

```tsx
<Menubar menus={MENUS} />
```
