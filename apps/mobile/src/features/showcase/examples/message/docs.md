## Installation

`Message` ships with the kit in `packages/ui-native/src/components/message.tsx`; there is nothing to install.

```showcase-example
c-message-1
```

## Usage

```tsx
import { Message } from "@workspace/ui-native/components/message";
```

```tsx
<Message author="Ava Patel" timestamp="09:41">
	<Bubble text="Hi!" />
</Message>
```
