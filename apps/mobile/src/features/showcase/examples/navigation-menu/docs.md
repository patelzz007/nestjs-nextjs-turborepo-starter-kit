## Installation

`NavigationMenu` ships with the kit in `packages/ui-native/src/components/navigation-menu.tsx`; there is nothing to install.

```showcase-example
c-navigation-menu-1
```

## Usage

```tsx
import { NavigationMenu, type NavigationMenuItem } from "@workspace/ui-native/components/navigation-menu";
```

```tsx
<NavigationMenu items={ITEMS} />
```
