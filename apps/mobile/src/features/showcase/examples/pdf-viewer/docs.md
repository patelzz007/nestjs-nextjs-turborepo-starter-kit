## Installation

`PdfViewer` ships with the kit in `packages/ui-native/src/components/pdf-viewer.tsx`; there is nothing to install.

```showcase-example
c-pdf-viewer-1
```

## Usage

```tsx
import { PdfViewer } from "@workspace/ui-native/components/pdf-viewer";
```

```tsx
<PdfViewer state={state} renderPage={renderPage} />
```
