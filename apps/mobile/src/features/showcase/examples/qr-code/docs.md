## Installation

`QrCode` ships with the kit in `packages/ui-native/src/components/qr-code.tsx`; there is nothing to install.

```showcase-example
c-qr-code-1
```

## Usage

```tsx
import { QrCode } from "@workspace/ui-native/components/qr-code";
```

```tsx
<QrCode value="https://acme.example/r/42" label="QR code to open the receipt" />
```
