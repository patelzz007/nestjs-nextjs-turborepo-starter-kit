## When to use

- Handing a link, a voucher or a pairing code to another phone

## When not to use

- Long text: send a link to it instead

## Notes

- Drawn as vector paths, sharp at any size
- Scanning lives in the kit's QR scanner (the same entry)

## QrCode

`QrCode` draws a value as a scannable QR code.

### Features

- **Any value**: a link, a code, text.
- **Accessible name** that says what scanning does.

## Integrating with other components

Show it in a Card or a sheet with the link written out beside it.

## Frequently asked questions

### Can people who cannot scan use it?

Write the link or code next to it; the QR code is a shortcut, not the only way.
