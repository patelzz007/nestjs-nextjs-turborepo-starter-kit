## Installation

`Rating` ships with the kit in `packages/ui-native/src/components/rating.tsx`; there is nothing to install.

```showcase-example
c-rating-2
```

## Usage

```tsx
import { Rating } from "@workspace/ui-native/components/rating";
```

```tsx
<Rating value={4.5} showValue />
```
