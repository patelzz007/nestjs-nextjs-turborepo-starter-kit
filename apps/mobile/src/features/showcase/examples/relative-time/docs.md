## Installation

`RelativeTime` ships with the kit in `packages/ui-native/src/components/relative-time.tsx`; there is nothing to install.

```showcase-example
c-relative-time-1
```

## Usage

```tsx
import { RelativeTime } from "@workspace/ui-native/components/relative-time";
```

```tsx
<RelativeTime value={updatedAt} now={now} locale="en-GB" />
```
