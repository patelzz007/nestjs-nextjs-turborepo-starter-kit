## Installation

`ScrollArea` ships with the kit in `packages/ui-native/src/components/scroll-area.tsx`; there is nothing to install.

```showcase-example
c-scroll-area-1
```

## Usage

```tsx
import { ScrollArea } from "@workspace/ui-native/components/scroll-area";
```

```tsx
<ScrollArea fadeEdges className="h-72">
	{ROWS}
</ScrollArea>
```
