## Installation

`Scrollspy` ships with the kit in `packages/ui-native/src/components/scrollspy.tsx`; there is nothing to install.

```showcase-example
c-scrollspy-1
```

## Usage

```tsx
import { Scrollspy, type ScrollspySection } from "@workspace/ui-native/components/scrollspy";
```

```tsx
<Scrollspy sections={SECTIONS} panelClassName="h-96" />
```
