## When to use

- Between groups of content: a heading and its body, rows of a summary
- Between inline items in a row (vertical)

## When not to use

- Between every line of a list: let spacing do it
- Inside a card or a box that already draws its edges

## Notes

- Decorative: hidden from screen readers
- Vertical rules take the row's height; give a short one a height (`h-8`)

## Separator

`Separator` is a thin rule in the theme's border colour, horizontal or vertical.

### Features

- **Orientation** `horizontal` or `vertical`.
- **Layout**: size and spacing through `className`.

## Integrating with other components

Use it between rows of a summary, beside a caption ("or continue with"), or between items in a toolbar row.

## Frequently asked questions

### Why is it hidden from screen readers?

It decorates; the groups it divides are already separate elements.
