## Installation

`Table` ships with the kit in `packages/ui-native/src/components/table.tsx`; there is nothing to install.

```showcase-example
c-table-1
```

## Usage

```tsx
import { Table, type TableColumn, type TableRow } from "@workspace/ui-native/components/table";
```

```tsx
<Table caption="Invoices" columns={columns} rows={rows} />
```
