## Installation

`UserAvatar` ships with the kit in `packages/ui-native/src/components/avatar.tsx`; there is nothing to install.

```showcase-example
c-user-avatar-1
```

## Usage

```tsx
import { Avatar } from "@workspace/ui-native/components/avatar";
```

```tsx
<Avatar name={name} imageUrl={url} sources={renditions} size="md" />
```
