**First live contact (2026-11-11):** Notion's handshake through the `webhooks.bishenpatel.com` tunnel was refused with 503. The request log showed why: the live service sends `X-Notion-Signature` on the handshake too, which Notion's documentation says it does not. The policy treated any signed request as an event. It now recognises the handshake by its body alone (one field, `verification_token`), still only while no secret is set. Two regression tests were added (policy and handler), and the ADR 084 row was corrected.

**First local `pnpm docs:sync` (2026-11-11):** it crashed with a raw ZodError on `DOCS_SYNC_REPORT_TOKEN=`, an empty line copied from `.env.example`, although `run` does not use that variable. The CLIs now drop empty variables (`packages/docs-sync/src/cli-environment.ts`, tested), so an optional one counts as unset and a missing required one gets the named-variable message.

**First live import (2026-11-11):** it created all 226 pages, then Notion refused one with 400 "Number of cells in table row must match the table width". The converter took the widest row as the width and did not pad shorter rows. It now follows GitHub-flavoured Markdown: the header row sets the width, short rows get empty cells, and cells past it are left out and listed in the import review. The 226 half-filled pages were moved to Notion's trash and the import was run again from the start.

**Second live import limit (2026-11-11):** a 480-row table was refused: Notion takes at most 100 children per request, table rows included. The table is now created with its first 100 rows, and `append` adds the rest to it in batches (tested with 250 rows). A check of all 226 pages against the other request limits (1,000 block elements and 500 KB per request, 100 rich-text items per array) found nothing else.

**`pnpm docs:import --fresh` (2026-11-11, owner's request):** starting over is now part of the command. `--fresh` moves every page in both Published databases to Notion's trash (restorable for 30 days), clears the saved progress, then imports. It is a flag rather than the default, so that a routine import can never delete pages writers made in Notion. `NotionWriter.trashAllPages`, `clearImportTargets` (tested), `NotionClient.queryAll` with no filter (tested), runbook and README updated.

**Notion labels cut off, plain yes/no (2026-11-12, owner's report):** reproduced in a browser with Mermaid 10.9.1 and 11.4.1: when the font changes after Mermaid measures a label, its HTML label (`white-space: nowrap` in a fixed box) is cut off, coloured or not. Fix, in the style block: an `init` directive for SVG text labels (they wrap inside the box and never clip) and one font (`sans-serif`) for measuring and drawing, the same font on every `classDef` in case a Mermaid ignores directives, and `themeCSS` making edge labels solid rounded pills with dark text (Mermaid draws them half see-through: the grey squares). **Notion pill text off centre, pills too narrow (2026-11-13, owner's report):** Mermaid writes SVG label text from its left edge, in a pill sized for that text at its own size and weight; the style block's CSS made the text 12px and bold, so it no longer filled the pill and sat to the left.
