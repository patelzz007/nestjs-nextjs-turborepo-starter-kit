# Progress: 2026-11-07

## Git hook dashboard

The owner found the commit and push display too thin and not interactive, so both hooks now open a full-terminal dashboard (`packages/tooling/src/terminal-progress/`).

| Area | Change |
| --- | --- |
| Information | What is being sent (branch, commits, files, lines), overall bar, time left from the last good run, per-package state, cached packages, slowest files, failed tests as they print |
| Keys | Six views, scrolling, a package's own log, cancel (`q` twice or Ctrl+C). Read from `/dev/tty`, because git owns a hook's stdin |
| Cancel | Signals the whole process group: SIGINT, then SIGTERM, then SIGKILL. A probe showed a background process can ignore SIGINT and hold the output open |
| After the run | A summary stays in the scrollback |
| Bug fixed | A check that exited non-zero without printing anything counted as a pass, because the verdict read the failure log. The verdict now reads the exit codes |
