# Progress: 2026-11-11

## Explicit state machines

The owner asked for every implicit state machine to be found, and for the change that best improves UX, DX and AX without breaking anything. The catalog is `docs/architecture/state-machines.md`.

| Finding | Count |
| --- | --- |
| Prisma enums named `*Status` / `*State` / `*Stage` | 33 |
| With an explicit transition table before today | 1 (rewards, a pair list) |
| Declared with `defineStateMachine` now | 5 (tenant, support access grant, store location, KYB review, reward review) |
| Real lifecycles still implicit (listed with owner and files) | 20 |
| Statuses that are not lifecycles (listed with why) | 8 |
| Lifecycles encoded in timestamps (listed) | sessions, passkeys, challenges, tokens, API keys, terminal pairing |

| Area | Change |
| --- | --- |
| Primitive | `defineStateMachine` in `packages/shared/src/lib/state-machine.ts`: named moves, `can` / `targetOf` / `sourcesOf` / `eventsFrom` / `toMermaid`. A definition with a state nothing enters or a dead end not declared terminal throws at load |
| API | `Tenant`, `SupportAccessGrantAggregate` (and its expiry query), `Location`, `MerchantVerification`, `Reward` guard with the tables. Errors, codes and messages are unchanged |
| Admin | Merchant lifecycle panel and support-access console read the shared tables. The KYB decision form offers only decisions the API allows: Approve/Reject disable, the status select narrows, a closed review says how it reopens. Before, it offered every status and the API answered 409 |
| Merchant | Lifecycle screen, support-access approvals card and store list (Resubmit) read the shared tables |
| Guardrail | `state-machine-catalog.spec.ts` fails when a new status enum has no decision, when a modelled enum gains an uncovered value, or when a diagram in the catalog no longer matches the code |

Behaviour the tables made visible (kept as is, listed under *Follow-ups* in the catalog): `Location.close` and `completePrimaryFromOnboarding` have no status guard; an onboarding application can reopen an approved KYB review; saving KYB notes without a status change is refused; nothing enters the tenant states `RESTRICTED`, `PENDING_DELETION`, `DELETED`.

The `@workspace/shared` export snapshot was already out of date (the uncommitted docs-publishing names); updating it for the new names recorded those too.
