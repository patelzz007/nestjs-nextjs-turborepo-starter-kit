# Progress — 2026-11-18: Node 26 and a pure-JavaScript Kafka client

Decision: ADR 088 (supersedes ADR 024's client choice).

## Done

| Area | What |
|---|---|
| Mobile tests | The showcase sweep unmounts each example after using it (they had stayed mounted under the next, their timers running on every step: the trace sweep went from 77 s to 12 s of CPU, the mobile suite from 497 s to 94 s). The trace "played out" test now really plays each demo to its end, timer by timer (`runOut`), and loads the examples once up front. Same code in expo-boilerplate. |
| Node | 26.13.1 (Node 26 LTS) everywhere: `.nvmrc`, every workflow's `NODE_VERSION`, `engines.node`, `eas.json`, the Docker image, the Droplet script, the docs. Same ICU (78) as 24, so date formatting is unchanged. |
| Kafka client | `@confluentinc/kafka-javascript` (librdkafka) → `@platformatic/kafka` 2.16.0. The Confluent binding has no build for Node 26; CI compiled it from source for nine minutes and failed every job's install. The new client is pure JavaScript. |
| Messaging | `buildKafkaClientOptions` (TLS, SASL, explicit retries), `observeKafkaClient` (client events → `kafka.client_log`), `withKafkaDeadline`, provisioning on the new admin API; the producer keeps idempotence, `acks = all`, the Java murmur2 key hashing and its typed failures. |
| Analytics consumer | Consumer group with auto-commit off; `consumePlatformEvents` commits each offset only after the inbox handler resolved. Heartbeat and lost-group events are logged. |

## Found along the way

| Problem | Fix |
|---|---|
| With `@platformatic/kafka`'s default retries, a send to — or metadata read of — a topic the broker does not know never settled (140 s and counting) | Retries always set explicitly (3 × 250 ms): fails in under a second. The publish keeps its own deadline (`KAFKA_DELIVERY_TIMEOUT_MS`) as well. |
| Branch coverage of the mobile app fell to 82.96 % once examples unmounted | The trace demos had only been covered by leftover examples' timers; the played-out test now runs them to the end (trace-2 48/48, trace-15 10/10, trace-22 31/34). 83.18 %. |

## Checks

`format`, `lint`, `typecheck` green on Node 26; messaging 158 tests, analytics-consumer unit 51 and e2e 16 (real broker: provisioning, drift, earliest / latest) green before the full gate.
