# Enhancements

A survey of the codebase (2026-11-02) for ways to strengthen what exists and add what a production
starter kit is still missing. Every item names its **evidence** (what was checked, with file paths), a
suggested approach, a rough **size** and a **priority**.

- **Size:** S (≤ 1 day), M (2–5 days), L (1–3 weeks), XL (more).
- **Priority:** **P1** fixes a security, data or reliability risk; **P2** removes real friction or
  completes a half-built feature; **P3** is polish, or a capability to add when a product needs it.
- **Verify first** marks an item whose evidence is strong but not conclusive: confirm it before starting.

Already planned elsewhere, so not repeated here: the Notion docs integration and TanStack Start docs site
(`docs/architecture/notion-docs-plan.md`), and in-house observability (ADR 069, waiting for your go).
